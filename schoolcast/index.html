Frequently Asked Questions

Can I install both on the same computer?
Yes! If you have a computer that acts as both the control center and a display screen, you can install both the Admin Setup and the Agent.
How do I connect the Agent to the Admin?
Once both are installed, open the Admin panel. It will automatically search for Agents on your network. You just need to click "Approve".
